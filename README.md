# Restaurant Management System

A multi-UI restaurant management application designed for both business owners and customers.
The system supports menu management, dynamic table layout creation, and customer-side
search and reservation workflows.  
This project represents an earlier implementation focused on backend logic and application flow.

## Application Flow

On launch, the application provides two entry points:
- Business
- Customer

Users can log in or create a new account with unique credentials including name, email,
password, and profile image selection.

## Business Interface

### Menu Management
- Add and edit menu items
- Upload food images
- Define price, rating, ingredients, and food type/category

### Table Management
- Create tables in any orientation for reservation planning
- Design restaurant-specific seating layouts
- View reservation status through a table status interface

## Customer Interface

- Search food items, restaurants, and food types
- Display food results with image, price, and rating
- Navigate from food selection to restaurant table layout
- Reserve tables by selecting time slots and number of people

## Reservation Handling

- Customer reservations are reflected on the restaurant’s business UI
- Table availability and reservation status are updated in real time

## Local Network Testing Setup

- Backend server hosted on a laptop
- Two Android devices used as clients
- All devices connected on the same local network

This setup was used to validate real-time interaction between business and customer UIs,
reservation synchronization, and backend-driven state management.

## Tech Stack
- Python
- Backend Server Architecture
- REST APIs
- Git & GitHub
